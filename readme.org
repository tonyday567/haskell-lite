#+TITLE: haskell-lite

A consolidated Emacs package for Haskell development: major mode, REPL, Cabal support, and org-babel integration.

* Components

| File | Purpose |
|------|---------|
| `haskell-lite.el` | Evaluation overlays and result display |
| `haskell-ng-mode.el` | Haskell major mode (tree-sitter font-lock) |
| `haskell-ng-repl-mode.el` | REPL interaction |
| `cabal-ng-mode.el` | Cabal file mode |
| `cabal-ng-consult.el` | Consult integration for Cabal |
| `cabal-ng-goto.el` | Navigation in Cabal files |
| `ob-haskell-lite.el` | Org-babel Haskell evaluation |

* Installation

Add to load-path and require:

#+begin_src elisp
(require 'haskell-lite)
#+end_src

This loads `haskell-ng-mode`, its REPL and Cabal components, and `ob-haskell-lite`.

* History

Previously split across three repos: `haskell-lite`, `haskell-ng-mode`, and `ob-haskell-ng`. Consolidated into `haskell-lite` for simpler maintenance.
